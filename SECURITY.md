# Report a security issue

Use GitHub private vulnerability reporting for a suspected issue in this catalog. Include the policy ID, affected revision and a bounded reproduction. Do not publish credentials or an exploit against a shared environment.

Catalogs contain instructions and optional commands. Only import reviewed commits from repositories you trust. forge validates structure and retains provenance; it cannot establish that arbitrary instructions or executable commands are safe for every host.

Enable executable gates only where the required tools and host permissions are appropriate. Production deployment, merging and source-control authorization remain separate explicit operations.
